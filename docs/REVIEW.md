# Move and formation review (October 2026)

Every move in the editor's pool and every formation, checked against the authorities:

- **CB**: The Caller's Box glossary (Chris Page and Michael Dyck). Read from the copy Ryan pasted earlier, because
  ibiblio.org's security certificate can't be verified from the cloud session.
- **T**: *English Country Dance Basics, a Tutorial* by George W. Williams V (upadouble.info), text.
- **GIF**: the tutorial's animations, which Ryan supplied. They were identified by matching each GIF's size to the
  tutorial page's image list. They appear to be drawn mirror-image, so directions follow the text and shapes follow
  the animations.

Verdicts: **✓** matches; **fixed** was wrong and is now corrected; **new** was not animated before this review;
**approx.** works but is simplified, or no animation was available to compare against. Approximations are flagged in
the move explorer.
